# LaunchBox Roadmap

这个文档用于约束 LaunchBox 的演进方向，并记录“规划中 / 已完成 / 下一步”的状态。目标不是一次性做成大而全的平台，而是持续把它打磨成一个顺手、稳定、可扩展的本地启动器。

## 产品方向

- 主要平台是 macOS
- 核心目标是提升本地工具、应用、脚本、链接的管理与启动效率
- 交互设计优先追求低摩擦、低认知负担、可快速上手
- 功能扩展遵循“先把高频操作做顺手，再补高阶能力”的原则

## 参考原则

项目会参考 Rolan 这类启动器产品的交互优点，但不会机械照搬。

重点学习这些方向：

- 右键菜单驱动的低摩擦操作
- 快速添加、快速整理、快速启动
- 少量分类 + 高频切换
- 轻量、稳定、响应快
- 对个人使用习惯友好，可逐步定制

## 分阶段规划

### Phase 1: 交互补强

目标：先把最常用的鼠标操作变顺手。

范围：

- 分类支持悬停自动切换
- 分类区域支持右键菜单
- 工具内容区空白处支持右键快速添加
- 分类项支持右键快捷操作
- 为后续批量操作预留统一菜单模式

状态：

- [x] 规划完成
- [x] 开发中
- [x] 完成

### Phase 2: 批量操作

目标：让工具管理从“单个编辑”升级为“成组整理”。

范围：

- 卡片选中态
- `cmd/ctrl` 多选
- `shift` 范围选择
- 批量右键菜单
- 批量移动分类
- 批量删除
- 批量改色

状态：

- [x] 已规划
- [x] 开发中
- [x] 完成

### Phase 3: 快速导入与应用库

目标：减少手动录入成本，让添加工具更自然。

范围：

- 应用库
- 常见目录扫描
- App 一键添加
- 文件拖拽导入
- URL 拖拽导入
- 快速创建快捷方式

状态：

- [x] 已规划
- [x] 开发中
- [x] 完成

### Phase 4: 快速启动体验

目标：把“找到并启动”这件事继续压缩到更少步骤。

范围：

- 命令面板
- 更强的搜索
- 最近使用排序优化
- 快速动作入口
- 全局唤起面板

状态：

- [x] 已规划
- [x] 开发中
- [x] 完成

### Phase 5: 工程与稳定性

目标：为持续迭代打基础。

范围：

- 参数解析升级
- 数据校验与迁移
- 更稳的存储容错
- 测试与 lint
- 更完善的 dev 流程

状态：

- [x] 已规划
- [x] 开发中
- [ ] 完成
