# app 图标修复

- 问题：新增 `.app` 工具时，使用“浏览”选择文件不会主动提取真实图标，保存后会回退成默认类型图标。
- 处理：
  - 在工具弹窗选择文件后立即根据路径提取图标并写入表单
  - `.app` 图标读取不再走 Electron `app.getFileIcon()`，改为从 bundle 的 `Info.plist` 和 `Resources/*.icns` 解析
  - 补充兼容 iOS 风格包装 app：支持外层 `.app/Wrapper/Runner.app`、`CFBundleIcons`、`CFBundleIcons~ipad`、`CFBundlePrimaryIcon`、`AppIcon60x60@2x.png` 这类 PNG 图标声明
  - `.app` 默认图标优先改为走系统 `NSWorkspace.icon(forFile:)`，直接拿 Finder 那张真实 app 图标，保证 iOS 包装 app 也能得到圆角图标
  - iOS 包装 app 里的 `CgBI` PNG 会先用 `sips` 转成标准 PNG，再回退用于兜底解析
  - 不在保存阶段兜底提取图标，避免编辑已有 app 时再次触发系统图标读取导致崩溃
  - 工具详情新增图标预览区，支持“使用默认图标 / 自定义图标 / 清除图标”
- 影响范围：
  - `src/main/index.ts`
  - `src/renderer/components/ToolModal.tsx`
- 验证：
  - 运行 `npm run lint`
  - 运行 `npm run typecheck`
  - 运行 `npm test`
