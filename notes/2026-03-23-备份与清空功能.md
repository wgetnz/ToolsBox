# 2026-03-23 备份与清空功能

## 目标

- 在设置中增加备份能力
- 支持立即备份
- 支持自动备份
- 支持清空所有数据

## 本次实现

### 1. 备份配置

在设置里新增了独立的“备份”页签，支持以下配置：

- 是否启用自动备份
- 备份目录
- 间隔备份
- 每日定时备份
- 每周定时备份

备份配置保存在 `settings.backup` 中。

### 2. 立即备份

新增主进程备份能力：

- 备份内容为完整 `AppData`
- 备份文件以 JSON 形式落盘
- 默认目录为用户数据目录下的 `backups`

立即备份会更新最近一次备份时间。

### 3. 自动备份

主进程增加了定时检查逻辑：

- 应用启动后开始轮询
- 设置保存后重新加载定时器
- 到达设定时间后自动执行备份

支持三种模式：

- `interval`：按小时间隔备份
- `daily`：每日指定时间备份
- `weekly`：每周指定星期和时间备份

### 4. 从备份恢复

新增“从备份恢复”动作：

- 设置页会自动加载当前备份目录下的备份列表
- 可直接从列表中选择某一份备份恢复
- 读取前会校验文件存在且内容非空
- 恢复前会先自动备份当前数据
- 恢复时会走现有 `sanitizeData`，避免旧格式或脏数据直接写回主数据

### 5. 备份列表与保留策略

补充了更完整的备份管理：

- 设置里可直接看到当前备份目录下的备份列表
- 列表展示文件名、时间、大小
- 支持从列表直接恢复
- 支持删除单个备份
- 支持一键打开当前备份目录
- 新增“保留备份数量”，默认保留最近 `10` 份
- 每次新建备份后，会自动清理超出数量限制的旧备份

### 6. 清空所有数据

新增“清空所有数据”动作：

- 执行前会先尝试自动备份当前数据
- 然后重置工具、分类和设置到默认状态
- 前端状态会同步刷新
