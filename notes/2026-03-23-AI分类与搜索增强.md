## 背景

- 搜索对中文场景不够友好
- 需要在设置里配置 OpenAI / Claude 兼容接口
- 导入 App 时希望可以通过提示词让 AI 自动创建总分类和子分类并归类

## 改动

- 搜索增强
  - 搜索文本改为归一化匹配
  - 统一处理大小写、全半角和空白
  - 搜索范围加入分类名称和路径

- 分类调整
  - `AI` 不再作为固定内置分类
  - AI 的职责改为“导入时根据提示词自动生成总分类和子分类”
  - 旧的 `daily-ai / ai / ai-clients` 遗留数据自动回落到 `临时收纳`

- 设置面板
  - 新增 `AI` 页签
  - 改为单一配置表单
  - 支持：
    - 启用开关
    - 提供方选择（OpenAI / Claude）
    - Base URL
    - API Key
    - 模型名称
    - 分类提示词

- AI 导入
  - 导入已安装 App 时，如果已配置 AI：
    - 先把应用元数据发给模型
    - 由模型输出“总分类 -> 子分类 -> 应用列表”JSON
    - 自动创建分类并导入应用
  - 如果 AI 未配置或调用失败：
    - 回退到本地规则分类

## 结果

- 搜索中文和分类名更容易命中
- 不再预置固定 `AI` 分类
- 可以通过一套统一的 OpenAI / Claude 配置，用提示词驱动 App 自动建分类并导入
