# 2026-03-23 工具自定义排序与菜单名修复

## 目标

- 修正 macOS 顶部系统菜单仍显示 `Electron`
- 恢复工具自定义排序
- 工具排序交互与分类排序保持一致，统一使用拖拽动画方案

## 本次实现

### 1. 系统菜单应用名修复

- 主进程启动后显式设置 `app.name` / `app.setName('ToolBox')`
- 补充自定义 macOS application menu
- 菜单第一项固定显示 `ToolBox`

### 2. 工具自定义排序恢复

- `Tool` 数据模型恢复 `customOrder`
- 数据清洗时保留旧数据中的 `customOrder`
- 新旧工具都会带上稳定的自定义顺序值

### 3. 工具拖拽排序

- 主内容排序菜单增加：
  - `自定义排序`
- 选中 `自定义排序` 时：
  - 网格视图使用拖拽排序
  - 列表视图也可拖拽排序
  - 动画和分类拖拽一致，基于 `dnd-kit`
- 拖拽保存走静默保存，不弹 toast
- 工具顺序改为批量一次性落盘，避免逐条保存导致拖拽后顺序自己跳动

## 说明

- 开发态使用 `electron .` 时，macOS 顶部最左侧应用名仍会显示为 `Electron`
- 这是当前开发二进制的进程名，不是窗口菜单模板文字
- 打包后的应用会显示为 `ToolBox`
