## 背景

- 启动日志出现 `Failed to load data: SyntaxError: Unexpected end of JSON input`
- macOS 下调用登录项设置时报 `Operation not permitted`

## 处理

- `src/main/store.ts`
  - 读取数据文件时，如果文件存在但内容为空白，不再直接 `JSON.parse`
  - 改为写回默认数据并正常启动

- `src/main/index.ts`
  - `app.setLoginItemSettings` 外层增加 `try/catch`
  - 权限不足时只记录警告，不影响设置保存和应用启动

## 结果

- 空文件场景不会再因为 JSON 解析失败导致启动报错
- 登录项权限不足时不会中断主流程
